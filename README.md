# odd_glc

`odd_glc` is the source project for **ODD General Life Cycle**.

It is a downstream ODD framework over GTL/ABG. It interprets admitted
requirements algebra, traversal, projection, fold, residual, and replay truth
as a general life-cycle construction framework.

`build_tenants/` will contain realization `HOW` when a build line is ratified.

This source project is not a release cut, not an install, and not ABG core.
