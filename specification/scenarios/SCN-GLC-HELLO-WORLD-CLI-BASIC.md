## Generic Lifecycle Capability

Single artifact execution proof.

Any governed lifecycle may need to prove that one produced artifact satisfies
one declared requirement under one execution capability.

## Trace

1. GTL declares the requirement: running the produced CLI artifact emits the
   declared greeting.
2. ABG admits the declaration and projects the active requirement environment.
3. ABG materializes or receives the target artifact as admitted payload truth.
4. ABG invokes the execution capability and admits command evidence.
5. ABG binds the evidence to the active requirement projection.
6. ABG emits fold, residual, and disposition truth.
7. odd_glc interprets the replay/query state as lifecycle readiness.

## Closure Expectation

The scenario closes only when replay/query truth shows:

- an admitted target artifact;
- admitted command evidence with the declared stdout;
- requirement evidence binding;
- satisfied assurance fold;
- no unhandled residual pressure.

odd_glc does not execute the command, admit evidence, or fold the requirement.
