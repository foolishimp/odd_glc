## Defect

The current data-mapper failure is not primarily a Scala/SBT or prompt wording
problem. It is a migration failure:

```text
odd_glc live runner
  -> installed ABG startup
  -> local promptFor/evaluatorPromptFor shell
  -> local helper compute inside plugins
  -> worker output
  -> local path/stage checks
```

The target path is:

```text
odd_glc GTL declarations + policy data
  -> installed ABG startup
  -> ABG traversal monad as the only closure-grade compute unit
  -> instructionAssemblyStartup admitted by ABG
  -> instruction_prompt_manifest_projected before F_P dispatch
  -> active requirement lineage delivered as prompt pressure
  -> worker consumes ABG manifest
  -> requirement-proof carry-through admitted by ABG
  -> obligation lineage monitored through proof coverage/fold/residual/replay
  -> replay/query truth interpreted by odd_glc
```

## Immediate Gate

Do not start another full data-mapper live run until T-030 Phase 5 and Phase 6
proofs pass. The next live proof should be a smaller software-build Hello
World traversal over the migrated T-183/T-188 path. Full data-mapper resumes
only after that path is proven.
